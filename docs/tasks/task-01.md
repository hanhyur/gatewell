# Task 01

- Goal
  Spring Boot 기반 애플리케이션 부트스트랩과 테스트 실행 기반을 만든다.

- Files
  `build.gradle`
  `src/main/kotlin/me/hanhyur/gatewell/GatewellApplication.kt`
  `src/main/resources/application.yml`

- Requirements
  Spring Boot 애플리케이션이 부팅 가능해야 한다.
  Kotlin + Spring Boot + validation + persistence + test 의존성이 추가되어야 한다.
  기본 설정은 로컬 개발과 테스트 실행이 가능한 최소 범위만 포함해야 한다.
  아직 비즈니스 로직은 넣지 않는다.

- Constraints
  초기 설정 외의 도메인 구현으로 범위를 넓히지 않는다.
  production 인프라 선택을 확정하지 않는다.
  테스트 가능성이 우선이며 불필요한 플러그인 추가를 피한다.

- Done Criteria
  애플리케이션 엔트리포인트가 생성되어 있다.
  테스트 러너와 Spring Boot 테스트 기반이 준비되어 있다.
  최소 설정 파일이 존재한다.
